# Contributing to OpenDental Atlas

Thank you for your interest in contributing to OpenDental Atlas!

We welcome contributions from:
- Dental professionals
- Medical and dental students
- Researchers
- Software developers

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your improvements.
4. Test your changes.
5. Submit a Pull Request with a clear description.

## Areas of Contribution

- Dental anatomy
- Oral pathology
- Maxillofacial surgery
- CBCT education
- Dental implantology
- Software development
- Translation (English and Uzbek)

## Medical Content Standards

All clinical and educational contributions should:
- Reference reliable scientific literature.
- Use evidence-based information.
- Include references where applicable.
- Avoid unsupported clinical claims.

## Code of Conduct

Contributors are expected to communicate respectfully and professionally.

Thank you for helping improve OpenDental Atlas!
